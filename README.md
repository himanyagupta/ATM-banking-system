# ATM Banking System

## A Python and MySQL based ATM banking system prototype with a Tkinter graphical user interface.

## About the Project

This project is a simple ATM simulation that demonstrates basic banking operations using Python and MySQL. It connects a Python application to a MySQL database to store and manage user account information.

## Features

- User account management
- ATM authentication
- Balance inquiry
- Cash deposit
- Cash withdrawal
- Database connectivity using MySQL
- Simple user interface

## Technologies Used

- Python
- Tkinter — for the graphical user interface
- MySQL — for database management
- MySQL Connector/Python — for connecting Python with MySQL
